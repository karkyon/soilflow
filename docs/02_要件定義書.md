## 1. システム化の目的

### 1.1 背景（現行の課題）

| 場所 | 現行のやり方 | 課題 |
|---|---|---|
| 土場 | オペレーターが実物を見て種別を判断し、無線で受付へ伝える | 課題なし。変えたくない（2026-10-12） |
| 受付 | 紙の受入日報に、来場時刻の「分」と「草」「○」を手書き。伝票を手書きし、紙にサインをもらって控えを保管 | 紙の保管、伝票の手書き |
| 本社 | 日報を回収し、台数を数え直して請求書に転記・計算し、郵送。freee会計へ売上を手入力 | 転記・数え直し・計算・郵送・会計への手入力の二度手間、転記ミスによる請求ミス |

### 1.2 目的

1. 受付の「紙に書く」作業を、同じ形の画面に入力する作業に置き換える。人の動きと無線のやりとりは変えない【確定】（提案書 P03）。
2. 受付の記入内容から、本社の集計・請求書の作成までを自動にし、転記・数え直しをなくす【確定】。
3. 請求書をメールで送り、郵送をやめる【確定】。
4. 送った請求書の売上と請求書PDFを freee会計 に自動で登録し、会計への手入力をなくす【確定】（2026-11-17）。
5. 伝票を電子サインにし、フジモト様控えを紙で保管しなくてよいようにする【確定】。

### 1.3 成功の目安

| 目安 | 導入前 | 導入後 |
|---|---|---|
| 本社での日報の転記・台数の数え直し | 毎日 | なし |
| 請求書の作成（月締め） | 請求先ごとに転記・計算 | 自動作成された内容の確認だけ |
| 請求書の送付 | 郵送 | メール |
| freee会計への売上の入力 | 手入力 | 確認して「freeeへ登録」を押すだけ |
| 受付の新しい操作 | ― | 「紙に書く」が「同じ形の画面に入力」に変わる一点だけ |
