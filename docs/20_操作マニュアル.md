# 20 操作マニュアル（受付編・本社編・管理者編）

| 項目 | 内容 |
|---|---|
| 対象 | SoilFlow を使う受付の方・本社の方・管理者（WBS 6.2） |
| 画面写真 | 試験の環境（試験用のデータ）で撮ったもの。`pnpm --filter e2e manual` で撮り直せる（docs/manual/img） |
| 関係する資料 | 05 画面設計書、16 移行・導入計画書、17 運用・保守手順書 |

SoilFlow は、受入日報の記入から伝票・サイン、月の締めの請求書、メール送信、freee 会計への登録までを1つで行います。ブラウザ（Chrome または Edge）で開き、配られたログイン ID とパスワードでログインします。

| 区分 | 最初に開く画面 | 主にすること |
|---|---|---|
| 受付 | 受入日報 | 日報の記入、伝票の発行、控えの印刷（現金のお客さまの領収書） |
| サイン端末（タブレット） | 待機画面 | 伝票を表示して、お客さまにサインしていただく |
| 本社 | 状況 | 日報・伝票の確認、紙伝票のスキャン、集計、締め、請求書の確認・メール送信 |
| 管理者 | 状況 | 本社のこと＋freee 連携・利用者・システム設定 |

---

## 1. 受付編

### 1.1 ログイン

![ログイン](manual/img/r01-login.png)

1. ログイン ID とパスワードを入れて「ログイン」を押します。
2. 初めてのときは仮のパスワードを変える画面が出ます。12文字以上で、よく使われるもの・ログイン ID を含むものは使えません。
3. パスワードを5回続けて間違えると15分ロックされます。急ぐときは管理者に「パスワード初期化」を頼んでください。

### 1.2 朝：前日の行を引き継ぐ

![その日の最初の日報](manual/img/r02-report-empty.png)

その日の最初に「前日の行を引き継ぐ」を押すと、前の日（日報のある日）の行（会社・現場・車番・品名・車格）をまとめて写します。便（時刻）は写しません。

### 1.3 行を追加する

![行の追加](manual/img/r03-row-dialog.png)

1. 「＋ 行を追加」を押します。同じ会社の車を足すときは、会社の下の「＋ 車番を追加（会社名）」が便利です（会社・現場・品名・車格が入った状態で開きます）。
2. 会社名は、読みがなの頭文字（あ・か・さ…）で絞り込んで選びます。
3. 現場・車番・品名・車格を選びます。新しい車番は入力するとそのまま車番マスタに登録されます。
4. 下の「日報の表示」で、紙の日報と同じ書き方（例：残土10t）になっているか確かめて「追加する」。

> 受入れと納品を同じ車が同時に行うとき（残土を降ろして山土を積む）は、品名の違う2行に分けます。

### 1.4 便を記入する（マスのクリック）

![記入した日報](manual/img/r05-report-filled.png)

- 車が来たら、その行の **今の時間帯（金色の列）のマス** を押します。今の「分」（例：10時24分なら「24」）が入ります。同じマスをもう一度押すと、もう1便足します。
- 記入した数字は、保存が終わるまで薄い色で表示されます。通信が悪いときは自動でやり直し、だめなら消えて赤いお知らせが出ます。
- 1つのマスには4便まで表示し、5便目からは「＋1」のように残りの数を出します。
- 右端の「台数」と、上の「本日 N台」は自動で数えます。

**車列（同じ時刻に何台も来たとき）**

![車列の記入](manual/img/r04-convoy.png)

左端の「車列」の欄にチェックを付けて、「選んだ N 行に今の時刻で記入」を押すと、同じ時刻でまとめて記入します。

### 1.5 印・時刻の修正・取消

![便のメニュー](manual/img/r06-trip-menu.png)

- 記入した「分」を押すと便のメニューが開きます。
  - **印**（草・○）を付けると品目が切り替わります（例：残土 → 残土（草根））。車列の便は「車列の全部に付ける」で一度に付きます。
  - **時刻** を直す・**取消** をする（取り消した便は台数に入りません。記録は残ります）。
- マスを **右クリック** すると、そのマスの便の一覧が開きます。
- 点線の下線の便は、伝票（サイン待ち以降）または送信済の請求書に入っているため直せません。伝票を取り消すか、本社で請求書を取り消してから直します。

**前の時間帯に後から記入する**

![後から記入](manual/img/r07-add-past.png)

前の時間帯のマスを押すと、分を選んで記入できます。今より後の時間帯・今日より後の日には記入できません。

### 1.6 伝票を発行して、タブレットでサインしていただく

![伝票発行](manual/img/r08-slip-dialog.png)

1. 「伝票を発行」を押し、左の一覧（伝票をまだ出していない便がある会社・現場）から選びます。
2. 右に伝票の見本（品名・台数・車番）が出ます。請求先は、現場・会社の既定で決まります。
3. **「サイン用タブレットへ送る」** を押します。タブレットに伝票が表示されます。
4. お客さまがサインして確定すると、受付の「伝票一覧」に **控えの印刷** が自動で開きます。複合機で印刷してお渡しください。

![サインが確定したとき](manual/img/r09-signed-print.png)

> タブレットが使えないときは「紙伝票で印刷」を押し、紙に手でサインしていただきます。紙伝票は本社でスキャンして登録します（2.2）。

**請求先を選び直すとき（運搬会社の車で、請求は元請など）**

![請求先の選び直し](manual/img/r10-slip-billing-change.png)

伝票発行の画面で請求先を選び直すと「既定から変えています」と出ます。理由（例：元請へ請求）を入れておくと、本社で確かめやすくなります。

### 1.7 伝票一覧

![伝票一覧](manual/img/r11-slip-list.png)

| 状態 | できること |
|---|---|
| 作成 | タブレットへ送る・紙に切替・取消 |
| サイン待ち | 送信を取りやめ（タブレットに出した伝票を引っ込める）・紙に切替 |
| サイン済 | 控えを印刷 |
| 紙で印刷 | 紙に切替（印刷し直し）・取消（スキャンの登録は本社） |

伝票を取り消すと、含まれていた便は「伝票未発行」に戻ります。送信済の請求書に入っている伝票は取り消せません。

### 1.8 現金のお客さま（設定で有効にしたとき・設計案）

![現金で受け取る](manual/img/r12-cash.png)

請求先の支払い方法が「現金」のお客さまは、伝票（サイン済・紙で印刷）から **「現金で受け取る」** を押します。

1. お預かりする金額（税込）と明細を確かめます。税抜5万円以上は、領収書に収入印紙を貼って割り印してください。
2. 宛名を確かめ（「上様」にもできます）、「○○円を受け取って領収書を出す」を押すと、領収書（お客さま用と控え）が開きます。印刷してお渡しください。
3. 伝票一覧の上に「本日の現金」の合計が出ます。閉める前にレジの現金と合わせてください。
4. 金額の誤り・返金のときは、本社で領収書を取り消します（受付では取り消せません）。

### 1.9 通信が切れたとき

画面の右上の表示が「● オフライン（記入できません）」になります。つながるまでは **紙の日報に書き**、つながってから SoilFlow に記入してください（後から記入：1.5）。

## 2. サイン用タブレット

| 待機 | サイン | 完了 |
|---|---|---|
| ![待機](manual/img/t01-waiting.png) | ![サイン](manual/img/t02-sign.png) | ![完了](manual/img/t03-done.png) |

- タブレットは「サイン端末」の ID でログインしたまま置いておきます（12時間で自動でログアウトします。そのときは受付でログインし直してください）。
- 受付から伝票が届くと自動で表示されます。お客さまに品名・台数・車番を確かめていただき、枠の中に指かペンでサインしていただきます。
- 「書き直す」で消せます。何も書いていないときは「確定する」を押せません。確定したサインは書き換えられません。
- タブレットには金額・請求先は出ません。

## 3. 本社編

### 3.1 状況

![状況](manual/img/o01-dashboard.png)

今日の台数・サイン待ち・伝票未発行の便、請求書の状態ごとの件数、freee の登録待ち・要対応の件数を見られます。数字を押すと、その一覧へ移ります。

### 3.2 受入日報・紙伝票のスキャン

![本社の受入日報](manual/img/o02-report.png)

受付と同じ日報を5秒ごとに更新して見られます。本社でも記入・修正できます（操作履歴に残ります）。

![スキャンの登録](manual/img/o03-scan.png)

「伝票」で、紙伝票（紙で印刷）の行の「スキャンを登録」を押し、複合機で PDF（300dpi）にしたファイルを選びます。PDF 以外は登録できません。

### 3.3 月の締め（請求書を作る）

![締めの前の確認](manual/img/o04-billing-precheck.png)

1. 「請求」で対象の月（既定は先月）を開きます。
2. **締めの前の確認** を見ます。

| 表示 | 意味と対応 |
|---|---|
| 赤：単価表に金額がない便 | その請求先の請求書は作りません。単価表（管理者）に金額を入れてから締め直します |
| 黄：伝票を発行していない便／サイン待ち | 伝票の出し忘れがないか受付に確かめます（締めはできます） |
| 黄：送付先メールがない | 請求先マスタにメールを入れます |
| 青：現金で受け取り済み | 現金の領収書を出した便は請求書に入れません |

3. 「締めを実行」を押すと、請求先ごとに請求書（作成済）と PDF を作ります。

### 3.4 請求書を確かめて確認済にする

![請求書の一覧](manual/img/o05-invoices.png)

![請求書の詳細](manual/img/o06-invoice-detail.png)

- 番号を押すと詳細が開きます。現場ごとの明細・小計・消費税・合計、PDF を確かめます。
- 便が後から変わった請求書は「要再確認」になります。「作り直す」で計算し直してください。
- 請求日・入金期日は「日付を変える」で直せます。
- 確かめたら「確認済にする」。一覧で複数選んでまとめて確認済にもできます。

### 3.5 メールで送る

![メール送信の確認](manual/img/o07-mail.png)

1. 確認済の請求書を選んで「選んだものをメール送信」。
2. 宛先・件名・本文・添付（請求書 PDF）・警告を確かめて「N 件を送信する」。
3. 送信済になった請求書の便・伝票は直せなくなります。直すときは「取消して再発行」（新しい番号の請求書を作ります）。
4. 「再送」で同じ内容を送り直せます（宛先を変えることもできます）。送信の記録は請求書の詳細に残ります。

### 3.6 集計

![集計](manual/img/o08-aggregates.png)

期間と「まとめ方」（日付・客先・現場・請求先・品目・車格から3つまで）を選びます。金額は税抜で、単価表の金額でその場で計算します。「CSV で出力」「Excel で出力」で保存できます。

![元の便](manual/img/o09-aggregates-trips.png)

行を押すと、その行に入った便の一覧が開きます。日付を押すとその日の受入日報、伝票番号からサイン入りの伝票・スキャン、請求書番号から請求書へ移れます。

### 3.7 現金の領収書（設定で有効にしたとき・設計案）

![現金の領収書](manual/img/o10-cash.png)

期間の領収書と、日ごとの現金の合計（取消を除く）を見られます。返金・金額の誤りのときは「取消」（理由が要ります）。取り消すと、その伝票の便は請求の対象に戻ります。

## 4. 管理者編

### 4.1 freee 会計との連携

![連携の設定（連携前）](manual/img/a01-freee-settings-before.png)

1. 「連携の設定」で「freee と連携する」を押し、freee の画面でフジモト様の事業所を選んで許可します。
2. 連携中になると、事業所の名前と許可した freee のユーザーが表示されます。登録のしかた（確認してから登録／メール送信と同時に自動で登録）を選べます。

![連携中](manual/img/a02-freee-settings.png)

**取引先・品目の対応付け**

![取引先の対応付け](manual/img/a03-freee-partners.png)

「取引先の対応付け」で「名前で自動照合」を押すと、名前が同じ取引先を対応付けます。候補が複数あるものは「freee から選ぶ」、freee にないものは「freee に作成」。

![品目の対応付け](manual/img/a04-freee-items.png)

「品目の対応付け」で、品目ごとに勘定科目・税区分（・freee の品目）を選びます。「未設定を『売上高・課税売上10%』で埋める」→「変更した N 件を保存」でまとめて設定できます。

**登録する**

![freee 登録](manual/img/a05-freee-registrations.png)

![送る内容](manual/img/a06-freee-preview.png)

メールで送った請求書は「登録待ち」になります。「送る内容」で取引（収入・未決済）の明細と証憑（請求書 PDF）を確かめ、選んで「freee へ登録」。登録済の行の「取引 ○○ ↗」で freee の取引の画面が開きます。要対応の理由（取引先・品目の対応付けがない など）は行に表示されます。

### 4.2 マスタ

![請求先マスタ](manual/img/a07-masters.png)

![請求先の修正](manual/img/a08-master-edit.png)

- 客先・現場・請求先・車番・品目・車格・印を登録・修正します。削除はせず「無効」にします（過去の記録には表示し、新しい入力の候補に出しません）。
- 請求先の **支払い方法** を「現金」にすると、現金のお客さまになります（システム設定で有効にしたとき）。

![単価表](manual/img/a09-price-tables.png)

**単価表**：品目×車格の1台あたりの金額（税抜）。黄色は参考値（㎥単価×容量＋積込料）と違う金額です。改定のときは「新しい単価表（今の表を写す）」で適用開始日を入れて作ります。請求書に使われた単価表は変更できません。

![CSV の一括登録](manual/img/a10-import.png)

**CSV の一括登録**：請求先 → 客先 → 現場 → 車番の順に、まず「確認だけする」で誤りを直してから「登録する」（16 3章）。

### 4.3 利用者・操作履歴・システム設定

![利用者管理](manual/img/a11-users.png)

- 利用者の追加・パスワード初期化で表示される仮のパスワードは、その場でしか見られません。本人に伝えてください。
- 受付の利用者には「対の端末」（伝票を送るサイン用タブレット）を設定します。
- 辞めた人は「有効」を外します（3か月ごとに棚卸し）。

![操作履歴](manual/img/a12-audit.png)

すべての記入・修正・取消・送信・freee 登録・設定の変更が残ります（書き換え・削除はできません）。行を押すと変更前・変更後が見られます。

![システム設定](manual/img/a13-settings.png)

会社名・登録番号・振込先・請求書の備考、税率と端数処理、日報の時間帯の列、メールの件名・本文のひな形、現金のお客さまを使うか、を設定します（変更は管理者だけ）。

## 5. 困ったとき

| 困ったこと | 対応 |
|---|---|
| ログインできない・ロックされた | 15分待つか、管理者に「パスワード初期化」を頼む |
| 「オフライン」と出る | 回線を確かめ、つながるまで紙の日報に書く |
| マスを押しても記入できない | 今より後の時間帯・今日より後の日ではないか。点線の下線（伝票・請求書で固定）ではないか |
| タブレットに伝票が出ない | 受付の利用者の「対の端末」、タブレットのログイン（12時間で切れる）を確かめる。急ぐときは「紙に切替」 |
| 控えの印刷が開かない | ブラウザのポップアップを許可する。伝票一覧の「控えを印刷」でも開ける |
| 締めで請求書が作られない請求先がある | 締めの前の確認の赤の表示（単価なし）を見る |
| 送った請求書を直したい | 請求書の詳細で「取消して再発行」 |
| freee が「要対応」 | 理由に出ている取引先・品目の対応付けをしてから登録する |
| 画面にエラーが出た | 表示された内容と「リクエスト ID」（エラーの詳細）を保守担当に連絡する |
