## 2. RPT-01 受入日報

紙の日報と同じ罫線・同じ並びにします（提案書 P06）。

| 項目 | 内容 |
|---|---|
| 用紙 | A3 横（設計案。Q-10） |
| 見出し | 「受入日報」、日付（曜日つき）、事業所名、本日の台数 |
| 列 | 会社名／現場（会社名は太字、現場名はその下に小さく）・車番・品名・時間帯（設定の最初〜最後の列、初期値 7〜16）・台数 |
| マス | その時間帯の便の「分」を記入順に並べる。印は分の右に「草」、左に「○」（紙の書き方に合わせる）。1マスに6便まで、7便以上は「＋N」 |
| 台数 | 会社のまとまりの最初の行に、会社ごとの合計（太字） |
| 並び | 画面と同じ（客先の並び → 行の作成順） |
| 取消した便 | 印刷しない |
| 行数 | 1ページ 40行。超えたら次のページ |
| 欄外 | 右下に印刷日時・印刷した人 |

## 3. RPT-02 伝票（お客さま控え）・RPT-03 伝票（フジモト様控え）

同じ内容で、表題の下の区分だけが違います。RPT-02 は印刷して手渡し、RPT-03 は PDF で保存します（印刷しない）。

| 項目 | 内容 |
|---|---|
| 用紙 | A5 横（設計案。Q-10。現行の伝票の大きさに合わせる） |
| 表題 | 「納品伝票（受入）」。右に「お客さま控え」または「フジモト様控え」 |
| 番号・日付 | 伝票番号（20260205-012）、日付 |
| 宛名 | 「三幸工務店 様」（日報の会社名） |
| 現場 | 百間川 |
| 明細 | 品名（日報表記（価格表品目）車格）・台数・車番。品目×車格ごとに1行、最大8行（超えたら2枚目） |
| 合計台数 | 明細の台数の合計 |
| 請求先 | 宛名と違うときだけ「ご請求先：○○ 御中」を出す |
| サイン | 「受領サイン」の枠にサインの画像。枠の下に確定日時 |
| 発行者 | 会社名・事業所名・電話 |
| 金額 | 出さない（現行の伝票に金額がある場合は Q-10 で決める） |

## 4. RPT-04 紙伝票

RPT-02 と同じ配置で、サインの枠を空けて印刷します。右上に「紙伝票」と出し、2枚（お客さま控え・フジモト様控え）を1回で印刷します。フジモト様控えは本社に回し、スキャンして登録します（FR-SLP-11）。

## 5. RPT-05 請求書

| 項目 | 内容 |
|---|---|
| 用紙 | A4 縦 |
| 上部左 | 郵便番号・住所・「三幸工務店 御中」（敬称は請求先マスタ） |
| 上部右 | 「請求書」、請求書番号、請求日、登録番号（T＋13桁）、発行者（会社名・事業所名・住所・電話）、社印（画像、任意） |
| 挨拶 | 「下記のとおりご請求申し上げます。」 |
| 金額の欄 | ご請求金額（税込）を大きく、入金期日、振込先 |
| 請求期間 | 2026年2月1日〜2026年2月28日 |
| 明細 | 現場ごとに小見出し → 品目（価格表品目名）・車格・台数・単価・金額。現場ごとの小計 |
| 合計の欄 | 小計（税抜）、消費税（10%対象 ○○円・消費税 ○○円）、合計（税込）。インボイス制度の「税率ごとに区分した合計と税額」を満たす |
| 備考 | 設定の定型文 |
| ページ | 明細が1ページに入らなければ次のページへ。合計の欄は最後のページ |
| 再発行 | 右上に「再発行（元の請求書：SF-2602-003）」 |
| 取消 | 取消した請求書の PDF は作り直さない（送ったものをそのまま残す） |
